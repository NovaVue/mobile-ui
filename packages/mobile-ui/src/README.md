# 移动端组件
## 设计原则
以下原则全部基于组件，单个组件必须遵循以下原则

例： 标题组件title和number组件，必须都支持大中小三个字号，但两种组件的字号可以不一样，这就是原则全部基于组件
### 1. 颜色
遵循原则，同一类颜色不超过三种

* 主题色：用于高亮
* 主色：用于基础
* 辅色：用于辅助
* 强调色：用于强调，不同组件强调色意义不同，例：百分比类，红色代表涨，绿色代表跌
* 背景色：
  * 基础背景色：用于页面级别，占用面积第一大
  * 主背景色：用于区分当前区域空间，占用面积第二大 主要用于容器组件，布局组件
  * 强调背景色：用于突出显示当前区域
* 特殊颜色：用于特殊场景，例：错误提示，成功提示，警告提示，加载提示，信息提示，提示，确认，取消，重置，提交，返回，关闭，取消，重置，提交，返回，关闭，取消，重置，提交，返回，关闭

### 2. 字体
* 字号：大 中 小 特殊需求用户自行控制
* 字体粗细：大 中 小 特殊需求用户自行控制

### 3. 间距
* padding:
  * 有间距：大 中 小
  * 无间距：无
* margin:
  * 有间距：大 中 小
  * 无间距：无

### 4. 边框
* 边框支持，border、box-shadow
* 所有容器组件均支持 border、box-shadow
